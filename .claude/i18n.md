# Internationalization Rules

## Setup
- i18next + react-i18next with browser language detection
- Languages: German (DE, primary) and English (EN)
- Fallback language: DE
- All translations inline in `i18n.ts` (no separate JSON files)

## Rules
- Every user-facing string MUST use a translation key via `t('key')`
- When adding new UI text: add both DE and EN translations in `i18n.ts`
- HTML in translations is allowed (rendered via `dangerouslySetInnerHTML`) — use sparingly
- Interpolation: `t('key', { variable: value })` for dynamic values
